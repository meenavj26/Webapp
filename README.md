
**BBC Good Food Recipe App**

A simple Streamlit web scraping app that collects recipe data from BBC Good Food and displays recipe names with ingredients.

**Live App**

[Open App Here](https://meenavj26-webapp-webapp-k4tacj.streamlit.app/)

**Features**

- View multiple recipes
- Shows ingredients

**Files**

- webapp.py- Streamlit app
- scrape.py- Scrapes recipe data
- recipes.json- Stored recipes
- requirements.txt- Required packages

**Installation**

pip install -r requirements.txt

**Run Scraper**

python scrape.py

**Run App**

streamlit run webapp.py

**Technologies Used**

- Python
- Streamlit
- Beautiful Soup
- Requests
- JSON
